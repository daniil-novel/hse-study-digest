Начни с `python digest.py status` и `python digest.py schedule` интерпретатором .venv из корня проекта. Проверь время успешного сбора и код состояния. Не выводи .env, токены, телефон и файлы авторизации.

Для одного реального сбора без письма используй `python digest.py service --once`. Для проверки MCP доступна команда doctor. Просроченный вход требует действий пользователя в собственном терминале; код Telegram и 2FA не запрашивай в чате.

Команды install-service и remove-service управляют автозапуском проекта. Выполняй их по запросу пользователя. Не создавай второй независимый планировщик доставки. Не меняй адрес получателя без поручения. При неопределённом результате SMTP сначала предложи проверить почтовый ящик, не удаляй запись pending ради повтора.

Установка скиллов сама по себе не запускает сервис. Сервис работает при доступном компьютере и сети, а пользовательский автозапуск — после входа в ОС. Не обещай работу выключенного ноутбука и бессрочную авторизацию провайдера.
