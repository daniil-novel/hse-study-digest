# Как программа находит учебные группы и извлекает задания

[Оглавление](README.md) · [Открыть код](../study_sources.py)

У этого модуля две работы. Сначала он помогает студенту выбрать учебные группы. Затем читает сообщения только в выбранных группах и превращает строки с поручениями в записи для таблицы. Текст разбирают правила Python на компьютере участника. Подключение к Telegram нужно для получения данных, но модель в этом модуле не вызывается.

## 1. Как предмет попадает в список кандидатов

Сначала участник открывает электронную зачётку, выписывает свои дисциплины, затем добавляет их обычные сокращения. Если в зачётке записано «Базы данных», а группа называется «БД | группа 2», полезен такой фрагмент словаря.

```json
{"Базы данных": ["БД"]}
```

Снаружи стоят фигурные скобки, потому что это словарь. Слева от двоеточия — одно официальное название. Справа — список вариантов названия в квадратных скобках. Пустой список `[]` оставляет только официальное название.

Функция `aliases_for` сравнивает заголовок чата с названиями и сокращениями. Она игнорирует регистр и лишние пробелы. Границы слова защищают от ложных совпадений внутри другого слова. Для «БД | группа 2» получится «Базы данных». В названии «Объявления второго курса» совпадения может не быть. Такой заголовок по-прежнему можно увидеть в списке активных кандидатов и проверить самостоятельно.

## 2. Что означают 300 диалогов и два месяца

В режиме `discover` библиотека Telethon перебирает до 300 диалогов, возвращённых Telegram. Верхняя граница применяется к диалогам **до** фильтрации. В эти 300 могут попасть личные переписки, но программа исключает их из результатов и не читает их историю. Программа оставляет группы и каналы, у которых дата последнего сообщения попала в окно наблюдения, и показывает дату и возможный предмет. У Telegram есть закреплённые диалоги, поэтому не следует считать перечисление исчерпывающим списком всех групп аккаунта в строгом временном порядке.

Функция `two_months_before` отступает на два **календарных** месяца с сохранением времени суток. Например, при запуске 4 ноября в 10:00 рассматриваются сообщения с 4 сентября 10:00 включительно. Для 30 апреля 2026 года нижняя граница — 28 февраля с тем же временем. Так обрабатываются месяцы разной длины. Чат, в котором было новое сообщение о встрече выпускников, формально активен. Его учебное назначение подтверждает студент по своему ИУП.

В каждой строке результата четыре значения. По порядку идут идентификатор чата, название, дату последнего сообщения в московском времени и возможное название предмета. Если нашлось несколько предметов, они перечислены через ` / `. Пустая подсказка означает только отсутствие совпадения названий. Участник выбирает нужные идентификаторы и сопоставляет каждому одну дисциплину. Универсальный чат курса с заданиями по нескольким предметам требует отдельной проверки перед включением.

## 3. Как программа читает выбранную группу

1. Функция `telegram` проверяет, установлена ли библиотека Telethon и заданы ли `TG_API_ID` и `TG_API_HASH`. Это идентификаторы приложения Telegram. Они нужны клиентской библиотеке для обращения к сервису.
2. При первом вызове с командой `login` клиент создаёт в закрытой папке файл сессии. В следующий раз файл позволяет снова подключиться под тем же аккаунтом. Его нельзя прикладывать к учебному отчёту.
3. При сборе проверяется соответствие «отрицательный числовой ID группы → точное название из словаря дисциплин». Один лишь похожий заголовок не включает чат в сбор.
4. Клиент читает выбранную историю от новых сообщений к старым. Дойдя до первой записи раньше нижней границы, он заканчивает чтение этой группы. Сообщение без доступного текста пропускается. Подпись к прикреплённому файлу может попасть в текст, содержимое самого вложения не разбирается.
5. Для публичного чата строится ссылка по имени группы и номеру сообщения. Для приватной супергруппы используется ссылка вида `https://t.me/c/…/…`, которая откроется у участника с доступом. Для старой группы без поддерживаемой ссылки в записи остаются название источника и номер сообщения.
6. После работы клиент разрывает соединение. Это происходит и при ошибке.

## 4. Откуда в таблице берётся дата

`from_text` делит сообщение на строки. Регулярное выражение `ACTION` ищет слова с указанием действия, например «пришлите», «загрузите», «дедлайн». `UNCERTAIN` ищет изменения или сомнения, например «перенос» и «предварительно». Каждая сработавшая строка отдельно передаётся в `exact_due`. Эта функция принимает ровно одну полную дату с явным указанием срока перед ней, например «до 09.11.2026» или «дедлайн 2026-11-09». Дата занятия рядом с просьбой «сдать завтра» не устанавливает дедлайн. Поддерживаются `2026-11-09` и `09.11.2026`, при наличии времени — часы и минуты. Функция проверяет, существует ли такая дата в календаре. Неверно записанное время и распознанная пометка другого пояса, например UTC, оставляют срок пустым. Для даты без пометки используется московское время проекта.

| Вымышленное сообщение | Что вернёт разборщик |
| --- | --- |
| «Сдайте отчёт до 09.11.2026 в 18:00» | Одна запись, срок `2026-11-09 18:00`. |
| «Пришлите отчёт до 09.11.2026» | Одна запись, известен только день. |
| «Сдайте расчёт к пятнице» | Одна запись с пустым сроком. |
| «Перенос сдачи с 09.11.2026 на 11.11.2026» | Одна запись с пустым сроком. В исходном тексте видны обе даты. |
| «Сдайте отчёт до 31.11.2026» | Одна запись с пустым сроком. Такой даты в календаре нет. |
| «Спасибо за семинар» | Ни одной записи. |

Строка имеет поля `course` (дисциплина), `task` (текст поручения), `due` (распознанный срок), `source` (источник) и `url` (ссылка, если доступна). Если преподаватель написал «Сдайте эссе» в одной строке, а дату — в следующей, модуль увидит поручение, но может пропустить дату. В такой ситуации проверяют сообщение по ссылке. Результат автоматического поиска всегда ограничен выбранными группами, периодом, формулировками и доступным текстом.

## 5. Как проверить одну функцию без доступа к Telegram

Из корня проекта откройте интерпретатор.

```text
python
```

Команда запускает Python в интерактивном режиме. Когда появится приглашение `>>>`, введите строки ниже по очереди. Сам знак приглашения вводить не нужно.

```python
from study_sources import exact_due
exact_due("Сдайте отчёт до 09.11.2026 в 18:00")
exact_due("Сдайте отчёт к пятнице")
exit()
```

Первая строка делает функцию доступной по короткому имени. Второй вызов должен вернуть `'2026-11-09 18:00'`, третий — `''`. Две кавычки подряд означают пустую строку. Последняя команда возвращает вас в обычный терминал. Это упражнение использует только вымышленные сообщения, поэтому для него не нужны аккаунт, ключи и сеть.

## 6. Что проверить при расхождении

| Что видит студент | Где искать причину |
| --- | --- |
| Нужной группы нет при поиске | Сверить дату последнего сообщения, посмотреть, вошёл ли диалог в отбираемые 300, проверить тип диалога. |
| Группа видна, но предмет не предложен | Найти название в зачётке и добавить однозначное сокращение. Ещё раз вызвать поиск. |
| Задание пропущено | Проверить, выбран ли чат, есть ли доступный текст и есть ли в той же строке формулировка действия. |
| Задание есть, срока нет | Посмотреть в источнике, был ли указан год, есть ли несколько дат, перенос или сомнение. |
| После повторного запуска источник снова прочитан | Модуль заново проверяет окно в два месяца. Это позволяет увидеть текущую версию исправленного сообщения. Формирование итоговой таблицы выполняет следующий этап. |

Если в вашей группе часто встречается своя однозначная формулировка, сначала воспроизведите пропуск на вымышленном примере, затем добавьте выражение в `ACTION` и проверьте ещё одно похожее бытовое сообщение, которое должно быть пропущено. Если обе строки попали в задачи, новое правило слишком широкое.
