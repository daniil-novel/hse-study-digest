# Учебный дайджест ВШЭ

> Архив учебной версии для Windows. Для воспроизведения этой инструкции скачайте [зафиксированный выпуск программы](https://github.com/daniil-novel/hse-study-digest/archive/670aa644cd3d2edf0548427b09f3eb998f549e33.zip). Основной практикум для macOS находится в [корневом руководстве](../../../README.md).

**Практикум для двух участников · Windows · 10 астрономических часов.** К концу работы у вас будет личная таблица с предметом, заданием, сроком и источником. По понедельникам и четвергам компьютер сможет присылать её на вашу почту. Начните с учебного примера. Для первого запуска хватит Python, подписка и аккаунты понадобятся позже.

Студент обычно открывает чат, ищет последнее сообщение о сдаче, проверяет карточку задания в Smart LMS и записывает срок. Здесь те же действия разделены между программой и человеком. Программа ищет объявления и собирает черновик. Агент Codex или Claude Code по смыслу выделяет задания из ваших записей. Вы выбираете источники и проверяете спорные строки по оригиналу.

**Куда перейти.** Чтобы увидеть результат без аккаунтов, выполните [первый запуск](#1-получите-первую-таблицу-за-пять-минут). Для рабочего дайджеста пройдите шаги 2–8. В [разборе программы по файлам](docs/README.md) объяснено, как построить каждый модуль и проследить путь одной записи от источника до письма. В конце этого руководства есть [упражнение по изменению правила](#самостоятельная-сборка-добавьте-правило-поиска-поручений) для вашей копии проекта.

| Откуда приходит информация | Как попадает в дайджест | Что проверяет студент |
|---|---|---|
| Индивидуальный учебный план (ИУП) | Один раз за учебный период записываем названия предметов и их сокращения | Правильный год, модуль, специализация |
| Группы и каналы Telegram | Поиск кандидатов по списку предметов. Сообщения выбранных групп разбираются локальными правилами | Содержание чата, переносы и относительные даты |
| Smart LMS | Личная краткая запись по карточке задания. Дополнительно можно подключить календарь дедлайнов, если доступен экспорт | Официальная дата, время, ссылка на карточку |
| Расписание пар | Открываем в приложении или кабинете для сверки названий | Время семинара само по себе ничего не говорит о сроке сдачи |

## 1. Получите первую таблицу за пять минут

1. Скачайте проект целиком. На GitHub это зелёная кнопка **Code → Download ZIP**. В Проводнике щёлкните архив правой кнопкой и выберите **Извлечь всё**. Откройте папку, где виден файл `study.py`. Выберите личную папку вне общей облачной синхронизации. По ходу занятия здесь появятся параметры доступа к вашим аккаунтам.
2. Щёлкните адресную строку Проводника, напишите `powershell` и нажмите Enter. Это откроет окно команд уже в нужной папке. Дальше набирайте по одной строке и нажимайте Enter. Дождитесь возвращения приглашения перед следующей строкой.
3. Введите `python --version`. Слово `python` запускает установленную программу, а `--version` просит показать номер версии. Нужна версия 3.11 или выше. Если Windows предлагает только магазин или версия ниже, установите актуальный Python для Windows с официальной страницы, затем откройте новое окно в папке проекта. [Python для Windows](https://www.python.org/downloads/windows/)
4. Введите `python study.py demo`. `study.py` — имя файла программы. Словом `demo` мы просим взять вымышленные данные. Это упражнение работает без сети.
5. В Проводнике откройте `out/demo/digest.html` двойным щелчком. В браузере появится таблица. Рядом лежит `digest.csv` — те же строки в формате для электронных таблиц. Если Excel открыл всё в одной колонке, используйте **Данные → Из текста/CSV**, выберите UTF-8 и разделитель «точка с запятой».

В примере дата запуска зафиксирована на 4 ноября 2026 года. Ожидайте четыре строки, даже если выполняете работу в другой день.

| Что найдёте в таблице | Почему получилось именно так |
|---|---|
| Отчёт по лабораторной № 2, 12 ноября в 23:59 | Объявление в группе и личная заметка совпадают. В одной строке видны два источника |
| План проекта, 18 ноября | Первая из двух разных дат для одинаковой формулировки |
| Тот же план проекта, 20 ноября | У обеих строк статус «Сверить разные сроки». Программа сохраняет обе версии |
| Разбор кейса «до пятницы» | Время и число из этой фразы не определены. В таблице стоит «Уточнить по источнику» |

Откройте таблицу в обоих форматах и проверьте, совпали ли предмет и срок. Этот запуск проверяет установку и вывод. Работу подписки вы проверите отдельно на шаге 5.

## 2. Составьте список предметов

1. Откройте iStudy, выберите вход через ЕЛК и роль студента. Войдите под университетской учётной записью. Откройте электронную зачётную книжку, выберите свой учебный год. ВШЭ указывает, что здесь отображаются элементы ИУП по учебным годам. Если нужен утверждённый план в полном виде или у вас особый ИУП, уточните его в своём учебном офисе. [iStudy](https://istudy.hse.ru/) · [ВШЭ об ИУП](https://www.hse.ru/studyspravka/plan/) · [Электронная зачётная книжка](https://www.hse.ru/studyspravka/zachetbook)
2. Сверьте текущие дисциплины со своим модулем. Персональное расписание доступно в разделе «Расписание» личного кабинета и в HSE App X. Приложение позволяет подписаться на расписание занятий из своего календаря. Эта подписка пригодится, чтобы отличить название пары от похожего названия проекта. Инструкции зависят от кампуса и программы. [Личный кабинет](https://lk.hse.ru/) · [Памятка ВШЭ по расписанию](https://economics.hse.ru/support/timetable) · [HSE App X от ВШЭ](https://play.google.com/store/apps/details?id=com.hse.app2&hl=ru)
3. Введите `python study.py setup`. Команда `setup` подготавливает папку `private`. Откройте `private/courses.json` правой кнопкой через **Открыть с помощью → Блокнот**, замените пример двумя своими предметами и сохраните файл.

```json
{
  "Анализ данных": ["анализ данных", "АД", "data analysis"],
  "Управление рисками": ["управление рисками", "риск-менеджмент"]
}
```

Слева от двоеточия стоит название, которое увидите в таблице, справа в квадратных скобках — сокращения и варианты из названий чатов. Пишите в двойных кавычках, ставьте запятую между предметами. Последняя пара обходится без запятой. Для первой пробы можно оставить учебные названия и использовать заметки ниже. Закройте файл и откройте его ещё раз, чтобы проверить сохранение.

В соседнем `private/settings.json` собраны переключатели. В исходном виде файл выглядит так. На следующих шагах редактируйте в нём только указанное поле.

```json
{
  "provider": "codex",
  "allow_cloud": false,
  "email_enabled": false,
  "chats": {},
  "lms_calendar": "",
  "lms_api_courses": {}
}
```

Поле `chats` хранит соответствия «группа — предмет», а `lms_api_courses` — номера курсов ВШЭ для дополнительного модуля REST. Пустые фигурные скобки `{}` означают, что соответствий пока нет. Пустая строка `""` в `lms_calendar` означает, что календарь отключён. С такими настройками можно собрать дайджест из одних заметок. Повторный `setup` сохраняет уже созданные настройки.

## 3. Найдите свои учебные чаты

Этот шаг можно отложить, пока работаете на примерах. Программа читает группы вашей учётной записи через Telegram API. При поиске кандидатов используется метаинформация диалогов. Тексты сообщений, названия групп и результаты разбора Telegram обрабатываются на этом компьютере. В правилах Telegram отдельно оговорены ограничения на использование материалов платформы при развёртывании ИИ. В этом практикуме агент получает собственные записи из другого источника. Перекладывать переписку в файл заметок для агента нельзя. [Telegram API Terms § 1.5](https://core.telegram.org/api/terms) · [Условия использования контента](https://telegram.org/tos/content-licensing)

1. Введите `python -m pip install -r requirements.txt`. `python` ведёт в тот же Python, которым запускали демо. `-m` попросит его запустить модуль `pip`, то есть установщик дополнений. `install` означает «установить», `-r` указывает на список в `requirements.txt`. По окончании сообщений об ошибке быть не должно.
2. Войдите на сайт разработчика Telegram **со своим номером**. Откройте **API development tools** и заполните форму приложения. Введите своё название и короткое имя проекта. Сервис выдаст два значения, `api_id` и `api_hash`. Они нужны локальной программе, чтобы подключиться к Telegram. [Кабинет Telegram](https://my.telegram.org/) · [Официальная инструкция](https://core.telegram.org/api/obtaining_api_id)
3. В поиске меню «Пуск» введите «Изменение переменных среды текущего пользователя». В разделе пользовательских переменных нажмите **Создать**. В первой переменной с именем `TG_API_ID` сохраните `api_id`, во второй с именем `TG_API_HASH` — `api_hash`. Имя набирайте точно, без пробелов. Нажмите **ОК**, закройте старое окно PowerShell и откройте новое из папки проекта. Это настройки вашего пользователя Windows, доступные программам, работающим от его имени. На общем компьютере используйте отдельную учётную запись.
4. Введите `python study.py login`. `login` запускает вход в Telegram. Введите номер с кодом страны, код из Telegram и при запросе пароль двухэтапной проверки. Ответьте на запросы **в своём окне**, передавать их напарнику не нужно. Появится `private/student.session`. Этот файл позволяет войти в аккаунт, храните его как пароль.
5. Введите `python study.py discover`. `discover` просматривает до 300 диалогов в порядке списка Telegram, отбирает группы и каналы с активностью в последние два **календарных** месяца и сопоставляет заголовки с вашим списком дисциплин. Например, при запуске 4 ноября граница приходится на 4 сентября. Канал с названием «АД» может оказаться и учебным, и посторонним. Заголовок даёт подсказку, а решение принимаете вы.
6. Откройте `private/candidates.csv` в Блокноте или в Excel. Если Excel пытается преобразовать ID в число, скопируйте его из Блокнота целиком, включая минус. В Telegram проверьте группу по названию и последним сообщениям. В `private/settings.json` найдите пустое поле `chats` и запишите только подтверждённые группы. Вот фрагмент для **одной** группы. Подставьте свой ID, остальные поля файла сохраните.

```json
  "chats": {"-1001234567890": "Анализ данных"}
```

После этого программа будет читать сообщения выбранной группы за последние два месяца при каждом сборе. В этой версии у группы один предмет. Общий чат потока с сообщениями по многим дисциплинам лучше оставить вне списка и взять задания по нужным курсам из Smart LMS. При смене модуля обновите предметы и повторите команду `discover`.

## 4. Добавьте задания из Smart LMS

Откройте Smart LMS ВШЭ и войдите через университетский экран авторизации. Внутри своего курса откройте конкретное задание, найдите окончание приёма работ и проверьте часовой пояс. Дата открытия задания и время начала семинара могут стоять рядом. Для дайджеста нужна дата, к которой требуется выполнить действие. В открытой документации ВШЭ мы не нашли универсального студенческого API-ключа. Для основного занятия достаточно одного из двух способов ниже. Если вуз выдал вам токен с правом чтения календарных событий курса, отдельно можно подключить автоматическое получение заданий через REST. [Smart LMS ВШЭ](https://edu.hse.ru/) · [Справка ВШЭ](https://www.hse.ru/studyspravka/lms) · [Дополнительный модуль Smart LMS REST](docs/lms_api.md)

**А. Свои короткие записи.** В файле `private/lms.json` замените пустой список своим описанием в одно-два предложения. Для занятий с агентом начните с вымышленного примера. Все названия, номер карточки и сроки ниже учебные.

```json
[
  {
    "id": "lab-1",
    "course": "Анализ данных",
    "text": "Мне нужно сдать отчёт по первой лабораторной до 2026-11-15 18:00.",
    "url": "https://edu.hse.ru/mod/assign/view.php?id=12345"
  }
]
```

- `id` — постоянное короткое имя записи. Второму заданию дайте другой `id`.
- `course` — точное название предмета из `private/courses.json`.
- `text` — ваша собственная формулировка. Только это содержательное поле предназначено для передачи выбранной модели. Исключите имена, персональные данные, закрытые материалы, секретные ссылки и тексты из Telegram.
- `url` — обычная ссылка на карточку задания, которую вы вправе использовать. В рабочем примере замените её на настоящую. Персональные экспортные ссылки, токены доступа и ссылки входа здесь не нужны.

Для второго опыта возьмите другое задание без опубликованной даты. Напишите своими словами действие и оставьте срок неуточнённым. Если преподаватель переносит срок, исправьте исходную запись и снова соберите таблицу.

**Б. Календарь дедлайнов (необязательно).** Откройте в Smart LMS «Календарь». Если ваш интерфейс предлагает **Экспорт календаря**, выберите события курсов и нужный период. В Moodle кнопка **Get calendar URL** выдаёт адрес подписки, а **Export** скачивает разовую копию. В разных версиях названия отличаются. Проверьте, попало ли в выгрузку хотя бы одно известное вам задание. Доступность экспорта в личном кабинете конкретного участника нужно проверить при выполнении практики. [Календарь Moodle](https://docs.moodle.org/en/Using_Calendar)

1. Введите `python -m pip install -r requirements-calendar.txt`. Команда устроена так же, как установка дополнения Telegram. Только в `requirements-calendar.txt` перечислены дополнения для работы с календарём.
2. Сохраните файл под именем `private/deadlines.ics` и укажите в `private/settings.json` поле `lms_calendar` со значением `"private/deadlines.ics"`. Если система выдала персональную ссылку, начинающуюся с `https://edu.hse.ru/calendar/export_execute.php?`, можно вписать её вместо пути. Тогда программа будет получать актуальную выгрузку при сборе. Сохранённый файл вы обновляете вручную. Адрес подписки может содержать токен. Не показывайте его в письме, видео, запросе модели или репозитории.
3. В календарной записи должны распознаваться предмет из вашего списка и явный смысл события как срока сдачи. Проверьте после запуска одно задание по оригинальной карточке, в том числе время. Если календарь не выдан или в нём отсутствует нужное задание, используйте способ А. Учебные пары из HSE App X в этот вход не подставляются.

**Проверка без аккаунта ВШЭ.** В `courses.json` добавьте предмет `"Алгоритмы": []` по образцу шага 2. В `settings.json` укажите `"lms_calendar": "examples/deadlines.ics"`. Выполните `python study.py run` для сборки подключённых источников и откройте `out/live/digest.html`. В учебном календаре два события. По «Алгоритмам» должна появиться одна строка «Срок сдачи отчёта по практике», 9 ноября 2026 года в 20:59 МСК. Второе событие — лекция. После упражнения очистите учебный путь, прежде чем собирать настоящий выпуск.

## 5. Подключите одного агента по своей подписке

CLI — программа, которой можно поручить задачу одной строкой в терминале. Здесь CLI позволяет Python дождаться ответа модели без открытой вкладки чата. Для сборки нужен один вариант из таблицы. Используйте собственную учётную запись с доступом к выбранному инструменту.

| | Codex через ChatGPT | Claude Code через Claude |
|---|---|---|
| Установка в Windows | Установите Node.js LTS с официального сайта, откройте новое окно в папке проекта, выполните `npm.cmd install -g @openai/codex`. `npm.cmd` — установщик из комплекта Node.js, `install` добавляет пакет, `-g` делает команду доступной из любой папки, `@openai/codex` — пакет OpenAI. | Введите `winget install Anthropic.ClaudeCode`. `winget` — установщик программ Windows, `install` означает «установить», `Anthropic.ClaudeCode` — имя пакета Anthropic. После установки откройте новое окно терминала. |

В живой ветке на входе до 300 диалогов, из которых локальный поиск отбирает группы и каналы с вашим подтверждением. В этой учебной команде на вход модели идут только три вымышленные группы из кода.

## 6. Соберите черновик и проверьте результат

Введите `python study.py run`. Команда `run` перечитывает подключённые источники и сохраняет файл `out/live/digest.html` для просмотра и таблицу `digest.csv` рядом с ним. Можно вернуться к настройкам, исправить название, добавить задание и повторить сбор. Отправка — отдельная команда следующего шага.

Сверьте таблицу в паре. Один участник читает строку, другой открывает источник. Ответьте на три вопроса.

1. **Предмет совпал?** Учитывайте схожие названия курсов и чатов. Если источник выбран неверно, исправьте соответствие в `chats`.
2. **Что именно нужно сдать?** В разных заданиях могут совпадать слова «подготовить отчёт». Сверьте тему и источник. Строки про перенос или отмену требуют проверки у преподавателя.
3. **Откуда известны дата и время?** Для дат в тексте программа предполагает московское время, поэтому для личной записи переведите в него срок другого кампуса и сверьте результат. Если сказано «к следующей паре» или «в пятницу», найдите уточнение. Запишите его в виде `2026-11-15 18:00`. Там, где преподаватель назвал только день, в таблице будет дата без часов и минут. При наличии другого часового пояса в объявлении Telegram откройте первоисточник и перепроверьте строку.

При проверке Telegram учтите границы сбора. Текст на скриншоте, голосовое сообщение, документ без поясняющего текста или задача, о которой последний раз писали три месяца назад, могут не попасть в список. Два независимых сообщения о переносе сохраняют смысл только при совместном чтении. Ссылки на частные группы открываются у их участников. В обычной группе без ссылки можно найти сообщение по названию и номеру из поля источника.

## Самостоятельная сборка. Соедините агента и таблицу

На шагах 1–8 вы собрали рабочую конфигурацию. Теперь соберите свою короткую цепочку из двух готовых модулей. Делайте это в папке проекта, в которой уже прошёл `probe`. Понадобится одна учебная заметка. Ожидаемый результат — новая таблица в отдельной папке `out/lesson`.

1. Откройте Блокнот и сохраните пустой файл рядом со `study.py`. В окне «Сохранить как» выберите тип **Все файлы**, имя `my_pipeline.py`, кодировку **UTF-8**. Отображение расширений включается в Проводнике через **Вид → Показать → Расширения имён файлов**. Так можно убедиться, что имя не заканчивается на `.py.txt`.
2. Наберите программу ниже. Если уже вошли через Claude Code, укажите `"claude"` вместо `"codex"`. Используйте только вымышленные записи. При запуске этого упражнения одна фраза уйдёт выбранному провайдеру.

```python
from datetime import datetime
from study import MOSCOW, OUT, PRIVATE
from study_agent import extract
from study_report import render

provider = "codex"
note = {
    "id": "practice",
    "course": "Алгоритмы",
    "text": "Сдать отчёт по поиску в графе до 2026-11-19 19:00.",
    "url": "",
}
rows = extract(provider, PRIVATE, [note])
render(rows, OUT / "lesson", True, datetime.now(MOSCOW))
```

3. Проследите путь данных. Первые четыре строки `from … import …` подключают нужные операции. `datetime` возвращает текущее время. `MOSCOW`, `OUT` и `PRIVATE` задают часовой пояс, место для результата и папку профиля. Переменная `provider` выбирает авторизованный CLI. В `note` лежат поля одной заметки. Вызов `extract` получает список из одной записи, запрашивает у модели цитату, проверяет её и возвращает строки таблицы в `rows`. Вызов `render` берёт эти строки и записывает файлы в папку `out/lesson`. Значение `True` добавляет отметку об учебных данных, `datetime.now(MOSCOW)` ставит текущую дату.
4. Сохраните файл и выполните `python my_pipeline.py`. Эта команда запускает именно написанную вами цепочку. Откройте `out/lesson/digest.html`. Ожидается одна строка про отчёт по поиску в графе со сроком **19 ноября 2026 года в 19:00**. Напишите, какой модуль запросил модель, а какой сохранил таблицу. Откройте CSV и проверьте текст цитаты по заметке.
5. Измените учебный текст на «Сдать отчёт по поиску в графе к следующей встрече». Снова выполните ту же команду. Смысл задания сохранится, но точную дату программа больше не выведет. Кнопка почты и настройки настоящих чатов для этого упражнения не нужны.

## Как сдать практику

Разделите проверку. Первый эксперт отвечает за источники и поиск заданий, второй — за извлечение, вывод и доставку. Затем поменяйтесь ролями и попробуйте пройти один блок по инструкции напарника.

| Проверка | Как показать результат |
|---|---|
| ИУП и поиск групп | Назвать два текущих предмета. Объяснить, почему один из кандидатов включён, а другой исключён |
| Точная дата | Сверить одну строку с карточкой задания, включая часовой пояс |
| Неоднозначный срок | Показать, что у задания без точной даты не появился выдуманный срок |
| Работа агента | На учебной заметке продемонстрировать ответ выбранного CLI. Записать, какую формулировку он распознал |
| Собственное изменение | Показать изменённое правило и сравнение количества строк до и после. Объяснить одно ложное срабатывание |
| Повторный запуск | Дважды собрать один набор, сравнить таблицы и проверить защиту от повторного письма |
| Доставка | Показать письмо владельцу и два выбранных дня в планировщике. До получения письма записать статус «настроено, доставка ещё не проверена» |

**Рабочая шкала для экспертов семинара — 10 баллов.** Предлагаем пять проверок по 2 балла за каждую. Для каждой проверки 2 балла означают, что участник показал результат и объяснил, как его получил, 1 балл — выполнена только одна из этих частей, 0 — обе части отсутствуют. Эксперты могут уточнить шкалу до начала практики.

| За что начисляются 2 балла | Наблюдаемый результат |
|---|---|
| Выбор источников | Справочник содержит текущие предметы, участник обосновал включение и исключение чатов |
| Работа агента | Участник выполнил извлечение и классификацию на учебном материале и показал, какие данные получает провайдер |
| Качество таблицы | Срок, конфликт дат и задание без срока сопоставлены с исходными фразами |
| Самостоятельная сборка | Своя цепочка дала таблицу, изменение правила проверено сравнением до и после |
| Доставка | Получено письмо себе, повтор подавлен, в планировщике видны два дня недели |

Для короткого видео покажите входной **вымышленный** пример, запустите сборку, найдите задание без срока, откройте настройки расписания. Если преподавателю требуется подтверждение доставки, покажите письмо от отдельного тестового ящика с замазанным адресом. В кадр и архив сдачи не включайте папки `private` и `out` с рабочими данными, список групп, секретные ссылки, пароли и файлы сессий.

## Если что-то пошло иначе

| Симптом | Следующее действие |
|---|---|
| Python сообщает, что `study.py` не найден | Откройте папку с этим файлом и запустите из неё новое окно PowerShell |
| Программа сообщает об ошибке JSON | Проверьте двойные кавычки, запятые и парные скобки. Откройте файл заново и сравните с примером |
| Учебной группы нет в списке кандидатов | Проверьте, когда было последнее сообщение и входит ли диалог в последние 300. Проверьте файл целиком, включая группы без совпадений в названии |
| Запрос CLI не проходит или истёк вход | Выполните `python study.py auth codex` или `python study.py auth claude` для своей программы, завершите вход в браузере и повторите соответствующую команду `probe`. Если ошибка осталась, проверьте сеть, лимит плана и обновление CLI по ссылкам шага 5 |
| Таблица пустая, хотя задание видно в браузере | Откройте карточку. Проверьте предмет, актуальность курса, выбранный период календаря, `id` чата и наличие текста. Добавьте свою заметку и повторите `run` |
| Вручную всё работает, а по расписанию — нет | Сверьте пользователя, программу, рабочую папку, сеть и питание. После создания переменных среды выйдите из своего сеанса Windows и войдите снова, чтобы задача получила новые параметры |
| Больше не хотите использовать доступ | Отключите задачу. Отзовите пароль приложения, завершите сеанс Telegram в «Настройки → Устройства», затем удалите ненужные пользовательские переменные и локальные закрытые файлы |
