# Соберите одну цепочку самостоятельно

[Оглавление](README.md) · [Основной практикум](../README.md)

Здесь участники сами соединят три части программы на вымышленном примере. Один пишет исходные фразы и ожидаемый результат, второй собирает обработку. Затем поменяйтесь ролями и проверьте спорный срок. Нужен только Python. Команды не читают аккаунт Telegram и не отправляют писем.

## Шаг 1. Согласуйте ожидаемый результат

Дано два сообщения по предмету «Алгоритмы». Первое — «Сдайте решение до 09.11.2026 в 18:00». Второе — «Подготовьте пример к пятнице». До запуска запишите на бумаге две строки, которые вы ждёте в таблице. Для первой получится точный срок. Для второй допустимо сохранить само действие и пометить срок для уточнения.

## Шаг 2. Получите записи

Откройте терминал из папки проекта и введите `python`. Вы увидите приглашение `>>>`. Вводите последующие строки без этого знака.

```python
from study_sources import from_text
one = from_text("Алгоритмы", "Сдайте решение до 09.11.2026 в 18:00", "Пример А", "")
two = from_text("Алгоритмы", "Подготовьте пример к пятнице", "Пример Б", "")
print(one)
print(two)
```

Первой строкой мы подключили только функцию разбора. При каждом вызове четыре аргумента передают ей предмет, сообщение, подпись источника и ссылку. Последнее значение `""` означает, что ссылки нет. В `one` и `two` сохранены **списки** найденных строк, поскольку в одном сообщении может быть несколько поручений. Вывод `print` позволяет увидеть, что функция определила до создания таблицы. В первом списке проверьте поле `due`, во втором найдите пустую строку в этом поле.

## Шаг 3. Добавьте второй источник и проверьте объединение

```python
from study_report import table
copy = from_text("Алгоритмы", "Сдайте решение до 09.11.2026 в 18:00", "Пример В", "")
rows = one + two + copy
result = table(rows)
print(len(rows), len(result))
print(result[0])
```

`from` и `import` делают функцию таблицы доступной по её имени. В строке `copy` записан второй, независимо подписанный источник с тем же действием. Знак `+` соединяет три списка. `table` получает три записи от источников, но должна вернуть две строки таблицы. `len` считает элементы, поэтому ожидаемый вывод — `3 2`. В нулевом элементе `result` будет поручение с точным сроком и двумя источниками. [Правило объединения](study_report.md)

## Шаг 4. Создайте результат, который можно показать коллеге

```python
from datetime import datetime
from pathlib import Path
from study_report import render
from study_sources import MOSCOW
folder = Path("out") / "practice"
now = datetime.now(MOSCOW)
page = render(rows, folder, True, now)
exit()
```

Первые четыре строки подключают работу с датами, путями, средствами вывода проекта и московским поясом. `Path("out") / "practice"` описывает вложенную папку. `now` хранит время создания отчёта. Аргументы `render` — исходные строки, папка, признак учебного примера (`True`) и время запуска. Присваивание имени `page` сохраняет HTML в памяти, а функция одновременно создаёт `digest.html` и `digest.csv` на диске. `exit()` закрывает интерактивный Python. Откройте файл `out/practice/digest.html` через Проводник и покажите коллеге обе строки.

## Шаг 5. Измените одно условие и объясните изменение

Ещё раз откройте `python`. Повторите шаги 2 и 3, но в записи `copy` замените число 09 на 11. Начальный текст двух записей про решение одинаковый, даты различаются. Теперь `print(len(rows), len(result))` должно показать `3 3`. Посмотрите `print(result)` и найдите две строки с пометкой «Сверить разные сроки». Объясните напарнику, почему автоматический выбор более поздней даты мог бы скрыть школьную или университетскую обязанность с ранним сроком.
