# Как проверяются календарные дедлайны

[Оглавление](README.md) · [Открыть тесты](https://github.com/daniil-novel/hse-study-digest/blob/670aa644cd3d2edf0548427b09f3eb998f549e33/tests/test_lms_calendar.py) · [Учебный календарь](https://github.com/daniil-novel/hse-study-digest/blob/670aa644cd3d2edf0548427b09f3eb998f549e33/examples/deadlines.ics)

Эти проверки защищают от двух особенно неудобных ошибок. Семинар может попасть в список заданий только потому, что у него есть дата. Личная ссылка календаря может случайно оказаться в итоговом письме. В файле `tests/test_lms_calendar.py` исходные данные вымышлены. Можно выполнить все проверки без доступа к SmartLMS.

## Как запустить только эти тесты

```text
python -m pip install -r requirements-calendar.txt
python -m unittest discover -s tests -p test_lms_calendar.py -v
```

Первой командой устанавливается библиотека, читающая формат iCalendar. `-m pip` запускает установщик из той же версии Python, `install` означает «установить», `-r` указывает файл со списком. Второй командой встроенный модуль `unittest` находит (`discover`) проверки в папке `tests` (`-s`), ограничивает их названным файлом (`-p`) и показывает каждый результат (`-v`). Если библиотека календаря не установлена, часть проверок помечается `skipped`, даже когда общая строка оканчивается словом `OK`. Установите пакет и запустите их повторно для полной проверки календаря.

## Расшифровка результатов

| Метод в файле | Что он делает и почему это важно |
| --- | --- |
| `test_reject_external_subscription` | Передаёт адрес вымышленного внешнего сайта. Программа отклоняет его до загрузки. Участник не должен случайно открыть произвольный URL как доверенный календарь ВШЭ. |
| `test_url_keeps_only_card_id` | Из адреса задания удаляется секретный параметр, остаётся числовой ID. При неизвестном сайте возвращается общая страница календаря ВШЭ. |
| `test_deadline_in_moscow_and_class_skipped` | Берётся файл с двумя событиями по предмету «Алгоритмы». В результате должно остаться одно поручение «Срок сдачи отчёта по практике», 9 ноября 2026 года в 20:59 МСК. Лекции в таблице быть не должно. |
| `test_all_day_floating_and_cancelled` | Тест создаёт временные копии календаря с тремя изменениями. Дата без часов остаётся датой, время без часового пояса получает пустой срок, отменённое событие пропускается. Исходный файл сохраняется. |

## Как добавить свой случай

Предположим, у учебной группы мероприятие называется «Напоминание о дедлайне». Решите с преподавателем, означает ли время этой записи фактическое закрытие приёма. Чтобы проверить поведение разборщика, создайте копию учебного файла и поменяйте только заголовок. Запустите `read_tasks`, как показано в [главе о календаре](lms_calendar.md), и сравните результат с ожидаемым. Осмысленный тест фиксирует обе стороны правила. Явный срок попадает в таблицу, а напоминание о нём — пропускается.
